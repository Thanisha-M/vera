# Vera — Psychometric Analysis Tool

Vera automates psychometric assessment scoring and reporting, cutting turnaround time from 1–2 days down to a few seconds.



\## Problem

Manual psychometric scoring is slow and inconsistent. Vera standardizes the process so results are ready instantly.



\## Features

\- Automated scoring of psychometric responses

\- Fast, repeatable report generation

\- Real-time assessment metrics



\## Tech Stack

\- \*\*Language:\*\* Python

\- \*\*Framework \& Libraries:\*\* Streamlit, Pandas

\- \*\*Deployment:\*\* Vercel / Streamlit Community Cloud



\## How It Works

Vera ingests raw user responses across key assessment questions and applies weighted scoring rules to calculate percentage scores across analytical thinking, team collaboration, and attention to detail.
